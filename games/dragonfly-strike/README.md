# Dragonfly Strike

**Game 1 · Helicopter action in a backyard garden**

A dragonfly gunship defends the Bug Kingdom from ant legions, in the style of the 16-bit games Desert Strike and Jungle Strike. Fly missions, winch up allies, chew through a destructible garden, dodge the lawnmower, level up and fight bosses.

**Play:** open `index.html` in Chrome or Edge.

**Xbox controller:** left stick fly · right stick aim · LB/RB spin · LT hold heading · RT or A gun · X bombs · B missile · Menu pause. Keyboard and touch also work.
