# Arcane Front

A Minecraft-style voxel war game in the browser. You are a battlemage of the Arcane Vanguard fighting three factions (Crimson Legion, Ashen Covenant, Iron Horde) for the villages of a procedurally generated world with plains, forest, desert, tundra and highland biomes.

- Guns: Arcane Rifle, Scattergun, Longshot sniper, Rocket Launcher, Gatling
- Spells: Fireball, Chain Lightning, Frost Nova, Meteor, plus Blink and grenades
- Command tablet: airstrikes, artillery, supply drops, sentry turrets, fireteams, forward operating bases, Orbital Lance
- Creative build mode with destructible terrain
- Capture villages to control biomes; take all nine to win

Open `index.html` in Chrome or Edge. Keyboard and mouse or an Xbox controller (press any button to connect).

## Controls

| Action | Keyboard / mouse | Xbox |
|---|---|---|
| Move · sprint | WASD · Shift | Left stick · L3 |
| Look | Mouse | Right stick |
| Fire · scope | Left · right click | RT · LT |
| Jump · fly | Space · double-tap | A · double-tap (L3 to descend) |
| Weapons | 1–9 / wheel | RB · D-pad ◀ ▶ |
| Reload · grenade · blink | R · G · F | X · LB · B |
| Build mode (break · place) | E (left · right click) | Y (RT · LT) |
| Command tablet | Q | D-pad ▲, A to call, RT to confirm |
| Squad follow / hold | T | R3 |
| Map · pause | M · Esc | View · Menu |
